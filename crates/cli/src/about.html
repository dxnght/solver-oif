What this is

A live, read-only view of real-time cross-chain intent flow (ERC-7683 / OIF), currently sourced from Across deposits on the configured origin chains. Each observed intent is run through the same routing/decision code (FillPolicy) the project's historical backtest uses, and the outcome — would_fill, a reason, a modeled profit, which gas source produced that number — is logged and streamed here. That's it.

This is Phase 1 (live shadow): a measurement exercise, not a trading system. Phase 2 (real filling) is intentionally parked.

What this is NOT

  • Not executing anything. Zero transactions, zero wallets, zero custody of funds. There is no execution path in this deployment.
  • Not a profit claim. would_fill and its modeled profit are a decision the code *would* have made, priced at evaluation time — not a realized trade. The project's own backtest, falsifying its original commercial thesis, found the honest cross-chain edge for a zero-inventory solo filler to be ≈ 0 (capital, latency, and volume competition eat the margin). The full methodology and numbers are in the linked write-up below — not repeated here to avoid two copies drifting apart.
  • Not investment advice. Nothing here should inform a trade.
  • Not full-coverage. Across is the only real-time source. UniswapX is ingested historically/retrospectively, not live. OIF stays idle by design — its settler contract address is unverified on-chain, and this project's rule is: unverified means untrusted, full stop, until proven otherwise against a live chain.

How to verify a number instead of trusting it

  • Verify links. Every decision backed by a real transaction carries a tx ↗ link straight to that chain's block explorer. Only known, verified explorer domains are ever linked — an unrecognized chain shows —, never a guessed URL.
  • Gas source, per row. Profit is gas-adjusted using a ladder — etherscan gas oracle → feehistory (eth_feeHistory RPC) → static fallback — and every profit figure shows which rung produced it, so a stale static estimate is never mistaken for a live one. Hover a profit value for the full gross − gas = net breakdown.
  • Persisted aggregates. The 24h/7d totals are recomputed from the append-only decisions log on disk (reports/live/decisions-*.jsonl), not just held in a browser tab's memory — a service restart doesn't reset them to zero.
